# Cine-ingressos
Projeto desenvolvido em Python para simular uma pequena bilheteria de cinema.
O projeto foi criado como parte dos meus estudos de Python e lógica de programação, utilizando estruturas condicionais e entrada de dados para criar uma experiência simples de recomendação de filmes e verificação de disponibilidade de ingressos.

Funcionalidades
Solicitação da idade do usuário
Recomendação de filme de acordo com a faixa etária
Verificação da quantidade de ingressos disponíveis
Validação da quantidade de ingressos solicitada
Mensagens de disponibilidade ou indisponibilidade

Regras de recomendação
Faixa etária	            Filme recomendado
Menores de 12 anos	      Rei Leão
12 a 17 anos	            Percy Jackson
18 anos ou mais	          A Hipótese do Amor


Conceitos de Python praticados

Variáveis
input()
print()
Conversão de dados com int()
Estruturas condicionais if, elif e else
Operadores de comparação
Validação de dados
Lógica de programação

Como executar
É necessário ter o Python instalado.
Clone este repositório ou baixe os arquivos e execute: cine-ingressos.py.
